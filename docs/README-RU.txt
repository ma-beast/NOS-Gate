NOS-Gate 0.3.12 PARALLEL DUAL HLS
=================================

Полный самодостаточный пакет исходников ветки 0.3. Внутренняя папка называется
NOS-Gate_0.3. Пакет можно распаковать отдельно либо поверх предыдущей версии.

БЫСТРОЕ ОБНОВЛЕНИЕ

1. Распаковать NOS-Gate_0.3 поверх существующей рабочей папки.
2. Подтвердить замену файлов.
3. Не удалять build и vendor\BearSSL\build.
4. Запустить build-vc6.bat.

ЧИСТАЯ СБОРКА

Архив содержит все исходники NOS-Gate и BearSSL. Для чистой сборки используется
build-full-vc6.bat. Собирать предыдущие пакеты по очереди не требуется.

ЧТО ДОБАВЛЕНО

* Локальный сервер обслуживает два запроса одновременно. Видео- и
  аудиосегменты HLS больше не блокируют друг друга в очереди.
* В локальный master-плейлист добавлен PROGRAM-ID=1 для VLC 2.0.8.
* У каждого обнаруженного MP4/HLS есть отдельная кнопка Play this source.
* Выбор по умолчанию не изменён: muxed MP4 либо muxed HLS около 360p.
* Из master-плейлиста извлекаются EXT-X-MEDIA TYPE=AUDIO, GROUP-ID и URI.
* VIDEO ONLY с найденной аудиогруппой помечается + AUDIO.
* При ручном запуске такого варианта NOS-Gate создаёт локальный master-плейлист
  из выбранного видео и связанного аудио.
* Видео- и аудиоплейлисты, сегменты и перенаправления проходят через NOS-Gate;
  проигрыватель не подключается к современному HTTPS напрямую.
* Для HLS MPlayer явно получает -cache 1024. MP4 не изменён.
* Добавлены журнальные строки HLS-AUDIO, HLS-VARIANT audio=YES/NO и
  HLS-LOCAL-MASTER mode=VIDEO+AUDIO.

Готового EXE в архиве нет: эталонная 32-битная сборка выполняется VC6.
Все исходники, BAT и тексты используют Windows CRLF.
Файл nos-gate-cookies.dat никому не передавайте.
