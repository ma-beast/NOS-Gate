NOS-Gate 0.3.18.9 ADAPTIVE LEGACY CARDS

База: 0.3.18.8 LEGACY CARD LAYOUT.

- Ограничение четырьмя колонками снято.
- Весь распознанный набор получает единый масштаб IMG 1/2.
- Ширина карточки = половина максимальной явной ширины IMG набора.
- Без явной ширины IMG: fallback 200 px.
- Карточки — простой старый float:left. Поэтому IE сам размещает столько
  карточек в строке, сколько реально помещается в текущем окне, и переносит
  остаток: N ... 4, 3, 2, 1 без знания разрешения со стороны Gate.
- После набора <br clear=all>, следующий контент не наползает.
- ORIGINAL не меняется.
- SINGLE HTTP и остальная логика 0.3.18.8 сохранены.

Лог:
LEGACY-CARD ... cards=N flow=adaptive half-width=XXXpx ...
