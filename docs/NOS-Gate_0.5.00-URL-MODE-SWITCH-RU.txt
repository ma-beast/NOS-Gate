NOS-Gate 0.5.00 URL MODE SWITCH

База: строго NOS-Gate 0.4.07 GENERIC IFRAME MEDIA TEST.

Единственное функциональное изменение:
переключатель ORIGINAL / LITE / SUPERLITE больше не использует
last_page_url как основной источник адреса.

Каждый frameset передаёт в свою верхнюю панель полный закодированный URL
именно той страницы, с которой эта панель была создана. Кнопки режима
открывают этот же URL заново через /go/, /light/ или /lite/.

Это специально решает простой случай с IE Back/Forward:
если IE вернул старую запись истории целиком (страница + её NOS-панель),
панель снова несёт URL этой старой страницы, а не последний URL из памяти Gate.

Старый /switch/* оставлен только как совместимый запасной обработчик,
но новые кнопки панели его больше не используют.

Медиадетектор, Generic IFRAME, Video control, 8 workers, сеть,
карточки, cookies/referer и прочая логика 0.4.07 НЕ МЕНЯЛИСЬ.

Старые описания находятся в docs/.
