NOS-Gate 0.4.07 GENERIC IFRAME MEDIA TEST

База: 0.4.06 MEDIA BAR TEST.

Минимальный следующий шаг: проверенный на Synchroncode разбор страницы плеера
теперь пробуется для ЛЮБОГО явного iframe, который NOS-Gate уже обнаружил на
родительской странице и сохранил в REFERER-MAP.

То есть тем же путём без специальных адаптеров сначала пробуются:
- Synchroncode;
- Videobalanser;
- Ashdi;
- Kinogram;
- другие уже уверенно найденные явные iframe-плееры.

Алгоритм НЕ считает любой открытый URL плеером: generic media parser запускается
только для URL, ранее найденного как iframe и записанного вместе с parent/referer.
Если внутри HTML найдены те же прямые поля download/HLS, что у Synchroncode,
показывается уже существующий экран Video с источниками/Play/Download.
Если не найдены — пишется MEDIA-GENERIC ... no direct source, после чего страница
идёт старым обычным путём. Поэтому неподдержанный плеер не должен ломаться.

Kodik/data-params и прочие динамические плееры второго порядка НЕ трогались.
YouTube -> NOS-Pipe пока тоже не менялся.
8 workers, LITE/SUPERLITE, карточки, сеть и Media Bar не менялись.

Старые описания находятся в docs/.
