NOS-Gate 0.4.05 VISIBLE MEDIA CONTROL

База: 0.4.04 MEDIA GROUP DIAG; рабочая многопоточная база 0.4.01 сохранена.

Первый видимый универсальный медиаслой:
- MediaList собирается из уже видимых NOS-Gate PLAYER/TRAILER;
- одинаковые URL/data-params удаляются как дубли;
- в начале BODY появляется один компактный блок Video control;
- готовые iframe становятся активными Player N / Trailer N;
- динамические data-params без готового URL показываются как
  Player N (... dynamic), но НЕ изображают работающую кнопку;
- известное имя провайдера используется только как подпись;
- неизвестный источник остаётся Player N;
- исходная страница и её собственная разметка плеера не удаляются специально.

Важно: это ещё НЕ NOS-Player. Озвучка/сезон/серия/качество не разбираются.
Сеть, 8 workers, cookies/referer guards, карточки и LITE/SUPERLITE не менялись.
Отложенный мини-фикс переключения режимов сюда не добавлен.

Старые описания находятся в docs/.
