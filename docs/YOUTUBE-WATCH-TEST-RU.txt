NOS-Gate 0.3.16 YOUTUBE WATCH TEST

База: 0.3.15 PAGE SAVE TEST ICONFIX3.
Рабочие HLS multiworker, OFF fix, локальный MPlayer, SAVE и иконка сохранены.

Добавлен отдельный SUPERLITE-парсер YouTube /watch:
- данные текущего ролика берутся из videoDetails внутри уже присланного HTML;
- рекомендации берутся из lockupViewModel;
- вывод: JPEG-превью, название, канал, длительность, ссылка;
- до 24 рекомендаций;
- JavaScript не исполняется;
- существующий YouTube search/videoRenderer не изменён.

Это тест навигации. Прямой запуск YouTube-видео этим патчем специально не добавлялся:
он не должен подменять уже рабочую медиалогику NOS-Gate/NOS-Pipe.

Проверка:
1. SUPERLITE -> поиск YouTube (должен работать как раньше).
2. Открыть ролик из поиска.
3. Должна появиться лёгкая watch-страница с текущим роликом и Related videos.
4. Нажать 2-3 рекомендации: каждая должна открыть такую же лёгкую страницу.
5. SAVE остаётся доступен для следующей диагностики стартовой YouTube/YammyAnime/ГидОнлайн.
