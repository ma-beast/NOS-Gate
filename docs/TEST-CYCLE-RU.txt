NOS-Gate 0.3.12 PARALLEL DUAL HLS — последовательность проверки
================================================================

1. СБОРКА

1. Для быстрого обновления распаковать архив поверх NOS-Gate_0.3 и запустить
   build-vc6.bat.
2. Для независимой чистой проверки распаковать архив отдельно и запустить
   build-full-vc6.bat.
3. Итоговая строка должна содержать 0.3.12 PARALLEL DUAL HLS.

2. РУЧНОЙ ВЫБОР

1. Открыть страницу Synchroncode.
2. У каждого источника должна быть кнопка Play this source.
3. MP4 должен оставаться помеченным как default, если muxed HLS отсутствует.

3. ДВУХПОТОКОВЫЙ HLS

1. Найти HLS 360p VIDEO ONLY + AUDIO.
2. Нажать его собственную кнопку Play this source.
3. В nos-gate.log ожидаются HLS-LOCAL-MASTER mode=VIDEO+AUDIO, запросы
   /media/hls/video.m3u8 и /media/hls/audio.m3u8.
4. Запросы аудио- и видеосегментов могут идти одновременно, без ожидания
   полного завершения предыдущего сегмента.
5. В nos-gate-player.log для MPlayer ожидается Cache size set to 1024 KBytes.
6. Проверить наличие звука, длительность воспроизведения и перемотку сначала
   в MPlayer, затем в VLC.

4. РЕГРЕССИЯ

1. Проверить обычный MP4 со звуком и перемоткой.
2. Проверить фокус страницы.

5. ЧТО ПРИСЛАТЬ

* nos-gate.log;
* nos-gate-player.log;
* build-vc6.log только при ошибке сборки.

nos-gate-cookies.dat не присылать.
